# Security

Report authorization bypasses, cross-guest data exposure, invitation/account
binding failures or key disclosure privately to **security@tenuo.ai**. Include the
Hermes Guests and Hermes versions, a minimal reproduction and the expected boundary.
Use synthetic accounts and resources when possible.

The [Tenuo security policy](https://github.com/tenuo-ai/tenuo/blob/main/SECURITY.md)
provides an optional encryption key for reports. Keep credentials, private keys,
invitation links and personal conversations out of public issues.

This release is a preview. Review the [security model](docs/advanced.md) and
[authorization details](docs/authorization.md) before connecting sensitive services.
