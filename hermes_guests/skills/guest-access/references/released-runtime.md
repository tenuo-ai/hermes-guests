# Runtime-first authoring

The current evaluated baseline is Hermes-Tenuo 0.4.0 and Tenuo 0.3.7.
Check the installed versions and APIs before giving advanced technical guidance.
The owner and guest happy path uses Hermes Guests' native tools and confirmations.

Hermes Guests uses Warrant builders, typed constraints, delegated chains, and HermesGuard
session assignment, replacement and clearing. The trusted local controller creates
keys, compiles the validated scope and signs after authenticated owner approval.
The model proposes permissions through management tools.

Use exact tool, action and resource restrictions. Review optional inputs and
cross-argument combinations. Preserve the approved end time unless the owner asks
to change it. Replacement must revoke superseded authority and invalidate old
session and child bindings. Verify current signed revocation data before claiming
that old authority has ended.

For advanced CLI guidance, inspect the actual installed commands and their help.
Keep routine sharing conversational and use the native approval flow.
